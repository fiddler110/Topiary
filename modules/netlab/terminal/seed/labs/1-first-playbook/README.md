# Lab A4: A first playbook: the web page

Serve a page on the web server with `copy`, `template` and a handler.

The full walkthrough, with every command explained, is the lab page **Lab A4** in the lab reader (the lab index
in your portal). This folder is where you do the work.

- You fill in: `labs/1-first-playbook/site.yml`
- Work from `~/netlab`, on branch **a** (`*-a-@POD@`).
- Check your work: `dojo netlab check A4`
- Stuck or wrecked the firewall or web node? `ansible-playbook reset_fw.yml -e branch=a`
