# Lab A1: Orientation with Ansible

Find out what is on each node by hand, then learn the same things with Ansible: inventory, ad-hoc commands and facts.

The full walkthrough, with every command explained, is the lab page **Lab A1** in the lab reader (the lab index
in your portal). This folder is where you do the work.

- You fill in: no starter file: you work from `~/netlab`
- Work from `~/netlab`, on branch **a** (`*-a-@POD@`).
- Check your work: `dojo netlab check A1`
- Stuck or wrecked the firewall or web node? `ansible-playbook reset_fw.yml -e branch=a`
